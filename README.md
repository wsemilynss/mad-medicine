# MAD MEDICINE · 医理探案

一个单文件的中医「四诊探案」交互剧场：望·闻·问·切收集线索 → 推理引擎辨证 → 生成身体状态侧写报告、调养处方与推理小剧场。电脑与手机浏览器均可打开。

## 在线体验

部署到 GitHub Pages 后，网址形如：

```
https://<你的用户名>.github.io/<仓库名>/
```

把这个链接发给别人，用电脑或手机浏览器打开即可使用。

## 本地预览

直接用浏览器打开 `index.html` 即可（视频需与 `index.html` 放在同一目录）。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部程序（界面、交互、知识库、报告导出），无外部依赖 |
| `reference-figures.mp4` | 中央「颗粒双人」视频素材，必须随网页一起发布 |
| `.nojekyll` | 让 GitHub Pages 原样服务所有文件 |

> 本作品为跨学科健康知识交互作品，所有「侧写」仅供学习参考，不构成医学诊断。

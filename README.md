# MAD MEDICINE · 医理探案

一个单文件的中医「四诊探案」交互剧场：基础建档 → 望·闻·问·切收集线索 → 阶段化人物侧写 → 推理引擎辨证 → 生成身体状态侧写报告、调养处方与推理小剧场。电脑与手机浏览器均可打开（移动端自动适配为抽屉式交互）。

## 玩法与特性

- **基础建档（可跳过）**：30 秒填写称呼、作息、饮食等，即刻生成「初步侧写」；赶时间可一键跳过直接开案。
- **线索板**：望·闻·问·切全部线索分组陈列（桌面端在左侧栏，手机端在底部抽屉，点按横条展开），点击任意一条作答，顺序自由；每条显示「待勘验 / 已归档 / 已略过」状态。
- **弹性答题**：望·闻·问可多选并存，每条证词独立使用五档程度条；可标记晨起、饭后、压力大等加重情境，用于交叉印证，也可自行补充证词。
- **自由跳过**：单题可「跳过此线索」，也可在线索板头部「跳过剩余 · 直接推理」。
- **阶段侧写奖励**：回收进度达 40% / 75% / 100% 时弹出「侧写更新」（初步轮廓 → 画像渐显 → 呼之欲出），快照自动记入线索簿。
- **切诊小游戏**：以掌心朝上手腕图标明拇指侧桡动脉与寸、关、尺，结合轻/中/重按压示意辨认脉象速率、深浅、力度与质感，并可自测真实心率。
- **理论与心理交叉**：十类证型包含中医经典理论、现代生理机制、心理模式与行为建议；新增心神问诊、压力/情绪/睡眠/躯体化四维心理侧写与交叉学科证据。
- **通关奖励**：身体侧写报告（六维雷达 + 五行能量轮）、证型解读、心理层面侧写、整合生活处方、五幕推理小剧场，支持导出独立 HTML 存档。

## 在线体验

部署到 GitHub Pages 后，网址形如：

```
https://<你的用户名>.github.io/<仓库名>/
```

把这个链接发给别人，用电脑或手机浏览器打开即可使用。

## 本地预览

直接用浏览器打开 `index.html` 即可（视频需与 `index.html` 放在同一目录）。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部程序（界面、交互、知识库、报告导出），无外部依赖 |
| `reference-figures.mp4` | 中央「颗粒双人」视频素材，必须随网页一起发布 |
| `界面效果参考.mp4` | 设计参考录像，仅存档用，不影响网页运行（可不发布） |
| `.nojekyll` | 让 GitHub Pages 原样服务所有文件 |

> 本作品为跨学科健康知识交互作品，所有「侧写」仅供学习参考，不构成医学诊断。

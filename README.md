# MAD MEDICINE · 怪物诊所（山海志异交互剧场）

一个单文件的中医「四诊寻妖」交互剧场：身体即山河，证型即精怪。挂号建档 → 望·闻·问·切捕捉异象 → 章节收录《怪物图鉴》→ 开坛辨证 → 生成身体状态侧写报告、手绘白描怪物图鉴卡、调养处方与山河志怪寓言小剧场。电脑与手机浏览器均可打开（移动端自动适配为抽屉式交互）。

**v6 怪物山海经视觉系统**：玄墨夜色为底，朱砂印为记；十证型对应十只手绘白描精怪（谷风雀、赤河鲤、露井蟾、暖灶兽、结木精、仓廪官、雾泽鲛、蒸岚蟒、石桥伯、烛宫鸦，另设山神「合瑞」），每只配仿《山海经》图鉴文（「有兽焉，其状如……」体）；怪物原画出自本项目 Reference/ 怪物角色设定手稿（本地素材源，网页使用 assets/img 优化版），暗底反白如碑拓，图鉴卡则印于宣纸。

## 玩法与特性

- **图标式开场与手册**：开场只保留一句话 + 四张图标步骤卡（建档 → 捕捉 → 通关 → 奖励）；手册改为六张图标卡，不再堆长文。
- **基础建档（可跳过）**：30 秒填写称呼、作息、饮食等，弹出「档案开启」：一幅初始六维雷达 + 一句侧写。
- **四章关卡**：望·闻·问·切各为一章，顺序自由。线索板顶部四枚章节徽章带进度环，点击可直接跳到该章下一条；收齐一章即全屏闪光「本章通关」，弹出奖励卡：徽章 + 当前雷达快照 + 一句证型洞见 + XP（无跳过为金徽，有跳过为银徽）。四章全收即「水落石出」，直接进入推理。
- **显影雷达**：线索板内的六维雷达随每一条证词缓动变形，后台权重条实时公开。
- **成就徽章**：初次锁定、四章全收、连击 ×3、细察入微（用过程度条 / 情境 / 自述）、指下有神（辨脉四问全对）、明察秋毫（零跳过），共 9 枚；解锁时右上角弹出 Toast，报告页附徽章墙。
- **答题面板减文字**：选项图示放大，题头配分组图标（寒热 / 头面 / 胸腹 / 饮食…）；「何时加重」与「自述补充」默认折叠，点「＋」才展开；所有答案统一先选中、再点击固定的「确认并归档」键，确认前可取消、替换答案、调整程度与情境标签，避免单击误触即提交；归档后镜头自动转向同章下一条光点。
- **弹性作答**：望·闻·问可多选并存，每条证词独立五档程度条；可标记晨起、饭后、压力大等加重情境做交叉印证，也可自行补充证词。
- **自由跳过**：单题可「跳过此线索」，也可在线索板「跳过剩余 · 直接推理」（被跳过收尾的章节不颁奖）。
- **切诊小游戏**：以掌心朝上手腕图标明拇指侧桢动脉与寸、关、尺，结合轻/中/重按压示意辨认脉象速率、深浅、力度与质感，并可自测真实心率。
- **理论与心理交叉**：十类证型包含中医经典理论、现代生理机制、心理模式与行为建议；心神问诊、压力/情绪/睡眠/躯体化四维心理侧写与交叉学科证据分级全部保留。
- **通关奖励**：侦探段位与徽章墙、身体侧写报告（六维雷达 + 五行能量轮）、证型解读、心理层面侧写、整合生活处方、可下载的推理路径图、五幕推理小剧场，支持导出独立 HTML 存档。

桌面网页版与手机网页版共用 `index.html`，会根据屏幕宽度自动切换为侧栏 / 底部抽屉布局；直接部署同一入口即可同时发布两端。

## 本地预览

直接用浏览器打开 `index.html` 即可（视频需与 `index.html` 放在同一目录）。在本地打开 `design-evolution.html` 时，「自动巡夜录制」对应的是同目录的 `index.html`；线上打开时则对应主程序网址。

## 自动同步发布

双击 `启动自动同步.bat`（使用 Windows 自带 PowerShell，无需 Node.js；也可运行 `node auto-sync.js`）后保持窗口开启：脚本每秒检查一次改动，每次保存 `index.html` / `design-evolution.html` 等待发布文件，脚本会自动提交并推送到 GitHub，GitHub Pages 随即重新发布，网页端与手机端共用同一网址、约 1 分钟后同时看到最新版本。按 `Ctrl+C` 停止。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部程序（界面、交互、知识库、图鉴、报告导出），无外部依赖 |
| `assets/img/` | 怪物白描与四诊小像的网页优化版（约 1100px JPEG），由 `Reference/` 原画批处理而来，须随网页一起发布 |
| `Reference/` | 怪物角色设定与情绪系列原画、剧场影像（本地素材源，体积大，不发布；见 .gitignore） |
| `design-evolution.html` | 设计演进对比说明页（五次视觉跃迁），辅助展示用，不影响主程序 |
| `system-analysis.html` | 系统架构与交叉学科知识体系分析页（含推理引擎微缩模型与「生命感」提升建议），辅助展示用，不影响主程序 |
| `interaction-life-design.html` | 交互生命感设计研究页（心跳节拍 · 显化仪表 · 由虚到实 · 多通道触感），辅助展示用，不影响主程序 |
| `theatre-interaction-analysis.html` | 剧场交互设计动态分析页（游戏思维 × 生命医学 × 心理学 × 剧场：九场戏剧弧线、交叉学科星图、机制×视觉×心理三轨联动、作用矩阵、科普意义、用户群定位）；分析时间轴按一局真实游戏实录逐秒标定，实录与图表同步播放；页内可录制下载约 103 秒 MP4 动态影片（含实录剪辑）、下载 2400×5120 静态分析长图（含 9 帧实录对照），辅助展示用，不影响主程序。本地 file:// 打开时浏览器禁止导出视频帧，导出的影片与长图会以抽象模型代替实录画面 |
| `gameplay-demo.mp4` | 医理探案一局完整自动演示的实录（约 162 秒，1280×744），供剧场交互分析页同步播放与导出，须随网页一起发布 |
| `exports/` | 上述分析页导出的动态影片（MP4）与静态分析图（PNG）本地存档，可直接分享；不参与网页运行 |
| `reference-figures.mp4` | 中央「颗粒双人」视频素材，必须随网页一起发布 |
| `界面效果参考.mp4` | 设计参考录像，仅存档用，不影响网页运行（可不发布） |
| `.nojekyll` | 让 GitHub Pages 原样服务所有文件 |

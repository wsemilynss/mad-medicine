一 · 研究框架：四根支柱FRAMEWORK

「医理探案」不是把医学知识「套上游戏皮」，而是让四个领域各司其职、彼此咬合：医学提供可信的内容，心理学定义要唤起的体验，游戏提供让体验发生的机制，剧场提供把它们串成一晚演出的结构。
生命医学CONTENT · 可信中医四诊与十证型为骨，现代生理机制、鉴别提示与 A/B/C 证据分级为肉——每个结论都能追溯。
心理学EXPERIENCE · 可感以好奇、自主、胜任、心流、内感受与宣泄为体验目标；以压力 / 情绪 / 睡眠 / 躯体化四维侧写身心。
游戏思维MECHANIC · 可玩捕捉 → 归档 → 通关 → 奖励的核心循环；XP、连击、9 枚徽章、段位与显影雷达构成短周期反馈。
剧场STRUCTURE · 可共情九场戏剧弧线、双人对坐的镜框舞台、幕间灯光、突转与发现、五幕推理小剧场与谢幕。

二 · 剧场化结构：九场戏剧弧线DRAMATURGY

整局游戏被组织为一出完整的戏：上方是剧场术语，下方是游戏界面。金线为戏剧张力，青线为视觉显影度（人影由虚到实），朱线为情绪效价。张力在每次「幕间闪光」后短暂回落，再于「突转 · 发现」处达到峰值——这正是弗赖塔格金字塔在交互中的复现。悬停或点击查看每一场。

三 · 剧场概念的交互转译THEATRE → INTERACTION

玩家同时扮演三个角色：侦探（主动推理）、病人（被侧写的身体）、观众（观看以自己为主角的五幕剧）。三者之间的往返，构成了「既入戏又出戏」的剧场张力；八个经典剧场概念被逐一转译为交互机制。

五 · 三轨联动：机制 × 视觉 × 心理MECHANIC · VISUAL · PSYCHE

本页的核心模型。把一局完整游戏压缩为一条时间轴：每一个机制事件（捕捉、通关、徽章、指认）都会立刻引发一处视觉变化（显影、饱和、闪光），再沉淀为一种心理体感（张力、心流、愉悦）。事件发生时，三轨之间会亮起因果涟漪。时间轴按一局真实游戏实录（自动演示 · 约 162 秒 · 建档 → 望闻问切 19 条线索 → 把脉 → 推理 → 报告 → 小剧场）逐秒标定：左下为实录画面，右下为对应的抽象「双人对坐」点云模型，三者共用同一时钟——拖动进度条或点击时间轴，实录同步跳转。

八 · 科普意义：知识的五级翻译SCIENCE COMMUNICATION

每个证型都沿一条「翻译阶梯」向上传递：经典概念 → 生活隐喻 → 现代机制 → 心理画像 → 行动处方，对应布鲁姆认知层级从「识记」走向「应用」。这让玩家不只是「被告知」，而是在游戏中完成一次可迁移的理解。点击证型切换。

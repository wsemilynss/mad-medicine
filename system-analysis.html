让系统接住人的意图

以鸿蒙为研究案例，从数字媒体、交互、文化在地性、行为认知与跨感官体验出发，梳理设备与使用者之间“生命感”的观察框架、研究方法和设计切入点。

核心认知：生命感不是把界面拟人化，而是用户在持续互动中感知到系统能恰当地回应、保持任务连续、解释自身行为，并让用户始终拥有选择和控制。

02 / LENSES

数字媒体设计

研究动态视觉、声音与时间如何表达状态。重点不是动效数量，而是反馈是否有意义、层级是否清晰、节奏是否合时。

状态可视化动态叙事表达节奏

交互设计

从用户目标出发检视操作、反馈、任务接续和错误恢复。设备可以互联，不代表任务上下文真的连续。

任务流可撤销恢复路径

文化在地性

从生活实践理解用户如何安排时间、共享设备、处理提醒与隐私。避免把文化简化成界面符号或单一默认生活方式。

情境访谈生活实践差异化默认

行为与认知心理

关注注意力、记忆负担、心理模型、不确定性和能动性。系统行为越稳定可预测，用户越容易建立信任。

认知负荷可预测性掌控感

跨感官体验

让视觉、声音、触觉互相补充而非重复轰炸；重要信息不能只依赖单一感官，反馈强度应可调节。

多通道编码无障碍感官负荷

隐私与负责任设计

情境适应与主动服务必须说明依据、权限和数据流向。尊重边界本身就是关系体验的一部分。

知情选择最小化用户控制

从观察到改进：研究证据链

04 / METHOD

界定任务与配置

记录设备型号、系统版本、应用、权限、网络和用户目标；避免将单一配置推广到整个系统。

观察完整旅程

记录操作、反馈、等待、切换、重复输入、失败和恢复，而不只截取页面状态。

三角验证

结合情境观察、可用性测试、访谈或日记研究，并用完成率、耗时、恢复率等补充。

验证设计机会

将发现连到用户影响、设计介入和可复测指标；分清主观感受与任务表现。

观察证据 → 用户影响 → 生命感维度 → 设计机会 → 验证指标

鸿蒙场景：优先检验的设计切入点

05 / OPPORTUNITIES
研究场景要验证的问题可介入方向建议观察证据
跨设备 / 跨应用接续用户是否知道传递什么，任务是否丢失或需要重做？从设备连接转向任务接续；保留进度，提供暂停、取消和恢复。重复输入、接续成功率、恢复耗时
系统状态与异常等待、权限不足、离线或应用不支持时，用户是否理解原因？明确表达当前状态和边界，为失败提供可操作的替代路径。状态理解度、误操作、求助与放弃
通知与主动建议提醒是否与当前目标相关，介入是否及时、可拒绝？允许接受、忽略、延后、降频与关闭；说明建议来源。采纳、关闭、打扰感与情境差异
卡片与系统入口是否展示可操作且新鲜的状态，还是增加信息噪音？优先支持高频轻任务，标明更新时间与后续入口。完成时间、入口选择、过期信息误用
多感官与无障碍提示是否一致、不过载，重要信息是否只靠一种感官？协调视觉/声音/触觉，并支持减弱动效和自定义通知。漏读率、可访问性测试、感官负担
共享设备与文化情境不同生活场景中，默认提醒、语气和隐私边界是否适合？基于研究调整默认值；提供可理解的权限与信息流控制。分群访谈、隐私理解度、偏好调整

优势与风险必须并置判断

06 / BALANCE
可能的优势 · 待验证

若系统入口减少重复步骤、跨设备任务确实接续、反馈清楚且一致，可能增强连续性、效率和被支持感。用真实用户任务验证，而不是用功能清单代替证据。

典型张力 · 需要权衡

适应性可能减少操作，也可能引起隐私担忧；主动提醒可能有帮助，也可能打断注意力；拟人表达可能亲近，也可能抬高不切实际的能力期待。

不宜预设 · 必须实测

具体体验会受系统版本、设备、应用、地区、权限与网络影响。本页提供研究框架，不对当前鸿蒙功能表现作未经验证的结论。

生命感 ≠ 拟人化　｜　恰当回应 + 连贯协作 + 可理解可控 + 长期可信
